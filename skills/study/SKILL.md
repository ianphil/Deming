# Study

1. Inspect the diff for correctness, scope, security, and contract issues.
2. Run the narrowest relevant tests or validation commands.
3. Compare the result with the prediction and record what was learned about the system.
4. Report the evidence, failures, limitations, and next change.

Done when every acceptance criterion has a result and the learning is recorded.
