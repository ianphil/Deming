# Plan

1. Read the relevant files and constraints.
2. State the goal, non-goals, files to change, acceptance criteria, prediction or hypothesis, and study method.
3. Choose the smallest change that satisfies the request.

Done when the plan is specific enough to implement without rediscovering the scope.
