# Spec skill sources

The decision-tree/frontier interview method is adapted from Matt Pocock's [grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md), reached via the user-supplied [grill-me](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md) wrapper. Both raw files were read from `main` on 2026-09-22; no source commit was observed, so these references are not claimed to be pinned. The method is integrated into Spec; the wrapper, external skill tree, and unavailable tool requirements are not runtime dependencies.

The output structure was adapted from the user-supplied `spec-template.md`: Problem, Solution, Non-Goals / Constraints, Context / Inputs, Deliverables, Definition of Done, and How You Are Graded. Deming adds draft status, assumptions, open decisions, and explicit workflow-selection provenance. The original local repository is not a runtime dependency.
